## About
Explore fundamental statistics terminology, how to calculate descriptive statistics for a data set using `pandas`, and how to join and merge data sets together.


## Learning Objectives

*You will be able to:*

- Understand basic statistical vocabulary and define different types of data.
- Compare measures of central tendency and spread.
- Summarize and visualize the shape of a variable.
- Explore descriptive statistics of a data set using `pandas`.
- Explain different kinds of joins, and merge data sets together using `pandas`.

## Prerequisites
- Write and run Python code in a Jupyter notebook.
- Create basic Python functions.
- Python programming skills including using modules and libraries.
- Basic knowledge of the `pandas` library.
- Understanding of the principles of data joins.
